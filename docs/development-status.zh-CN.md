# 开发状态｜作品集摘要

[English](development-status.md) | **简体中文** · [返回作品集](../README.zh-CN.md)

**独立项目持续研发中，尚不是开发完成或通过生产验收的 AI 助手。**

本页只记录**稳定的工程里程碑**，不逐日同步私有仓库进度。

### 已建立的工程基础

- Python/FastAPI 和 React/TypeScript 应用基础、浏览器本地数据和私人记录生命周期。
- 来源资料核验、Canonical Knowledge 契约、检索与索引表示、ChromaDB 集成及 RAG 评估工具。
- 结构化对话状态、来源/时间/身份校验、受限事实 ADD/REVISE/RETIRE 操作和受控记录权限接口。
- 后端、前端、浏览器和容器自动化检查，以及隔离的模型/工具测试基础设施。

### 仍在集成和验收的内容

- 通用的两阶段语义理解 → 能力规划流程。
- 公共证据、本地历史工具、证据后判断与对话/记录状态管理之间的完整协作。
- 真实模型、真实浏览器多轮验证和人工语义/安全审核。

### 此作品集不宣称

- 已有可公开运行的完整端到端 Demo 或持续在线服务。
- 新双 LLM 工作流已成为正式运行路径。
- Benchmark 或 Schema 检查通过就意味着医疗回答正确或工具执行不受限制。

**更新原则：** 只有当重要架构和产品里程碑改变以上边界时再更新，不需要跟着每次 commit 或 PR 修改。
